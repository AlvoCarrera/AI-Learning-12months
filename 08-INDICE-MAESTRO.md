## 🎯 WORKFLOW SUGERIDO

### **Inicio de cada SEMANA:**
1. Abre archivo fase actual (02, 03, 04, 05)
2. Lee sección de la semana
3. Busca en `06-CURSOS-UDEMY-ORDEN.md` qué curso tocar
4. Copia `07-SEGUIMIENTO-SEMANAL-TEMPLATE.md` → `SEMANA-XX-SEGUIMIENTO.md`
5. **ACCIÓN:** Empieza Udemy course

### **Durante la SEMANA:**
1. Diariamente: 2 horas (Udemy ~1h, Práctica ~1h)
2. Viernes: Rellena `SEMANA-XX-SEGUIMIENTO.md` con progreso
3. Si te atascas: `08-RECURSOS-EXTERNOS.md` → documentación oficial

### **Final de SEMANA:**
1. Completa checklist en `SEMANA-XX-SEGUIMIENTO.md`
2. Escribe 3 key learnings
3. Identifica bloqueadores
4. **Envía a Claude:** "Mira mi progreso SEMANA-XX"

### **Final de FASE (cada 12 semanas):**
1. Revisa todos tus `SEMANA-XX-SEGUIMIENTO.md` de esa fase
2. Resume: qué aprendiste, qué te costó, logros
3. Asegúrate completaste PROYECTO FINAL de esa fase
4. Publica en GitHub con README excelente
5. Move to next phase ✅
